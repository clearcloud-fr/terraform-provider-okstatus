# okstatus Provider

Manage OKStatus (okstatus.eu) monitors, monitor groups, incidents, status pages, alert channels and maintenances as code.

[OKStatus](https://okstatus.eu) is uptime monitoring hosted in Europe: websites, APIs, servers, databases and cron jobs, checked from several regions, with alerts, status pages and SLA reports.

- [Terraform guide](https://okstatus.eu/docs/guides/terraform/): every monitor type, alert channels, groups, private agents, import.
- [Tutorial: monitoring as code with Terraform and CI](https://okstatus.eu/docs/tutorials/monitoring-as-code-terraform-ci/): a complete project applied by GitLab CI or GitHub Actions.
- [Heartbeat monitors](https://okstatus.eu/docs/monitors/heartbeat/): watch cron jobs and backups.
- [API keys and access levels](https://okstatus.eu/docs/api/authentication/): Full key for `apply`, Read-only key for `plan`.

## Example Usage

```terraform
terraform {
  required_providers {
    okstatus = {
      source = "clearcloud-fr/okstatus"
    }
  }
}

provider "okstatus" {
  # api_key can also come from the OKSTATUS_API_KEY environment variable.
  # api_key = "oks_live_..."
}
```
